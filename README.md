# PULSO · Trailer

Trailer interativo da campanha PULSO, Brazil Conference 2027.

Site: https://rogeriobie2016-ship-it.github.io/bc27-pulso/

Este repositório guarda só o build estático publicado no GitHub Pages. O código-fonte fica no projeto `bc_pulso` (TanStack/Vite) e o build sai de:

```
node node_modules/vite/bin/vite.js build --config vite.pages.config.ts
```

Depois, copie o conteúdo de `dist-pages/` (sem a pasta `__grok`) para a raiz deste repositório.
